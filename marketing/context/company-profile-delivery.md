# Company Profile — Delivery Instructions

## Destination
This company profile is built for cloud delivery: Google Docs, Google Slides, or a PDF exported to Google Drive. Local files are just for processing — the final version lives in the cloud where you can open it directly.

## Source files in this folder
| File | Purpose |
|---|---|
| `company-profile.md` | Full profile text — copy into Google Docs/Slides |
| `brand_voice.md` | Tone, phrases, do/don't language |
| `assets/logo-placeholder.svg` | Temporary logo stand-in — replace with `logo.png` |
| `assets/README.md` | Logo usage rules, brand colors, typography |

## Build checklist (Google Docs/Slides)
1. Open Google Docs/Slides → new document
2. Paste `company-profile.md` content
3. Insert real logo as `marketing/context/assets/logo.png` (add it first)
4. Apply brand colors: Deep Trust Blue `#0066CC`, Fresh Teal `#00B4A6`, Healthy Amber `#FFB800`
5. Add photos: staff in PPE, delivery vehicle, Certificate of Potability, storefront, filtration equipment
6. Export as PDF → upload to Google Drive → share link

## Where the logo goes
- Cover page (large)
- Header on every page (small)
- Social avatars / Google Business profile
